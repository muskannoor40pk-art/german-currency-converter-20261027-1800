## Overview
The Currency Converter (German Edition) is a streamlined, single-file web utility designed for users in the DACH region. Whether you are a developer looking for a clean UI reference or a user needing a quick, offline-ready calculation tool, this project provides a reliable experience without the complexity of external API keys or build pipelines.

## Features
*   **Swap Functionality:** Instantly toggle between base and target currencies.
*   **Popular Currencies:** Pre-configured with major global and European currencies.
*   **Built-in Rates:** Includes a demo exchange rate engine for immediate usability.
*   **Zero Dependencies:** No external libraries or API keys required; perfect for privacy-focused environments.
*   **Responsive Design:** Optimized for both desktop and mobile viewports using modern Flexbox and Grid layouts.

## Localization Notes
